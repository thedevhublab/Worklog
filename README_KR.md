# Worklog

HTML, CSS, Vanilla JavaScript로 만든 가벼운 한국어·영어 지원 업무일지입니다. 매일의 업무를 기록하고, 분류로 정리하고, 월별·분류별·키워드별로 돌아볼 수 있습니다.

## 웹 앱

[Worklog 열기](https://thedevhublab.github.io/Worklog/) · [English README](README.md)

## 주요 기능

- **업무일지 작성:** 업무 날짜, 선택 마감일, 제목, 상세 내용, 분류, 선택 소요 시간을 기록하고 수정·복제·삭제합니다. 복제하면 원본 정보를 채운 새 초안이 오늘 날짜로 열리며, 저장 전까지 기록에 추가되지 않습니다. 제목은 필수이며 최대 80자, 상세 내용은 최대 3,000자입니다. 시간은 0~24시간 범위에서 30분 단위로 입력합니다.
- **작업 상태:** 왼쪽 Status 메뉴에서 전체 기록이나 `Create`, `In Progress`, `Complete`, `Cancel` 상태별 기록을 확인합니다. 기록 목록이나 작성·수정 창에서 상태를 변경할 수 있으며 상태는 기록과 함께 브라우저에 저장됩니다. 기존 기록과 상태가 없는 백업 데이터는 `Create`로 읽습니다.
- **상태별 요약:** 전체 기간과 선택한 월의 상태별 기록 수를 비교합니다. 상태 카드를 누르면 해당 상태의 기록을 목록에서 확인할 수 있습니다.
- **주간 요약:** 월요일부터 일요일까지 한 주의 업무 기록을 날짜순으로 보고, 날짜별 기록과 상태별 개수를 확인합니다. 이전 주·다음 주로 이동하거나 이번 주로 돌아올 수 있습니다.
- **마감일:** 업무 날짜와 별도로 선택 마감일을 저장합니다. `Complete`·`Cancel`이 아닌 업무의 마감일이 지나면 기한 초과로 표시합니다. 마감일이 없는 기존 기록도 계속 사용할 수 있습니다.
- **날짜 변경 안내:** 날짜가 바뀐 뒤 앱을 열거나 앱을 계속 사용 중이면 오늘 날짜의 새 기록을 작성할지 묻습니다. 동의하면 오늘 날짜가 입력된 기록 창을 엽니다. 전날 기록은 날짜별로 보존됩니다.
- **월간 대시보드:** 이번 달 기록 수, 전체 기록 수, 기록을 남긴 날짜 수를 확인합니다. 대시보드의 이번 달 통계는 목록에서 선택한 조회 월과 별도로 계산합니다.
- **다국어 달력:** Worklog 자체의 날짜·월 선택기를 사용합니다. 월 이름, 요일, 달력 레이블, 연도 이동 버튼이 선택한 언어에 맞춰 표시됩니다.
- **검색·필터·정렬:** 월과 분류별로 필터링하고, 제목·상세 내용·분류 이름을 검색합니다. 최신순, 오래된순, 제목순으로 정렬할 수 있습니다.
- **사용자 지정 한영 분류:** 분류를 추가·이름 변경·삭제할 수 있습니다. 한국어와 영어 이름을 사용자가 직접 입력하며 자동 번역 API는 호출하지 않습니다. 분류를 삭제해도 업무 기록은 보존되고 다른 분류로 이동합니다. 분류는 최소 1개 이상 남아야 합니다.
- **한국어·영어 인터페이스:** 상단에서 언어를 바꿉니다. 언어 설정은 현재 브라우저에 저장되며, 언어를 전환해도 현재 검색어·분류·조회 월은 유지됩니다.
- **JSON 백업 및 복원:** 마감일을 포함한 업무일지, 분류, 번역 이름을 JSON으로 내보냅니다. 가져오기 전에 파일 전체를 검증하고 병합 여부를 확인합니다. 마감일이나 상태가 없는 이전 기록도 계속 지원합니다. ID가 같은 기록은 가져온 내용으로 교체하고, ID가 없는 기록에는 새 ID를 부여합니다. 현재 버전 1 백업과 기존 배열 형식 백업을 지원합니다.
- **CSV 내보내기:** 현재 필터링된 기록을 날짜, 제목, 상세 내용, 분류, 상태, 소요 시간, 마감일과 함께 내보냅니다. UTF-8 BOM과 CSV 이스케이프로 한국어와 쉼표·따옴표·줄바꿈을 보존합니다.
- **반응형·접근성:** 모바일과 데스크톱에 맞춰 레이아웃이 바뀝니다. 입력 레이블과 오류 안내, 키보드 포커스 표시를 제공하고, 모달은 키보드와 Escape 키로 조작할 수 있습니다.
- **동작 줄이기 설정:** 기기의 동작 줄이기 환경 설정을 따릅니다.

## 시작하기

최신 브라우저에서 index.html 파일을 열면 됩니다. 로컬 사용에는 패키지 설치, 빌드, 계정, 서버가 필요하지 않습니다.

1. 날짜와 제목을 입력하고 필요에 따라 상세 내용, 분류, 소요 시간을 추가합니다.
2. 월 선택, 분류·상태 필터, 검색, 정렬 메뉴로 기록을 찾고 주간 요약으로 월요일부터 일요일까지의 기록을 돌아봅니다.
3. 사용자 지정 분류를 만들 때 한국어와 영어 이름을 모두 입력합니다.
4. 반복 업무는 복제한 뒤 새 초안을 수정해 저장합니다. 필요하면 마감일을 추가합니다.
5. 현재 필터 결과를 CSV로 내보내 스프레드시트에서 분석할 수 있습니다. JSON 백업을 정기적으로 내보내고, 가져올 때는 현재 브라우저 데이터와 병합합니다.

## 데이터 및 개인정보

Worklog는 브라우저에서 실행되는 정적 앱입니다. 마감일을 포함한 업무일지, 분류, 분류별 언어 이름, 언어 설정은 현재 브라우저의 localStorage에 저장됩니다. 계정, 서버 데이터베이스, 기기 간 자동 동기화 기능은 없습니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으니 JSON 백업을 별도로 보관하세요.

업무 기록을 번역 서비스로 전송하지 않습니다. DM Sans와 Noto Sans KR 글꼴을 Google Fonts에서 불러오며, 연결할 수 없으면 시스템 글꼴을 사용합니다.

## 테스트

현재 프로젝트에는 `tests/` 폴더나 자동화 테스트가 포함되어 있지 않습니다. 자동화 검증 코드를 추가하면 `tests/`에 모아두면 됩니다. 데이터 검증, 상태와 마감일 처리, 백업 호환성, CSV 형식이 코드 변경 후에도 올바른지 확인하는 데 사용할 수 있습니다. 테스트 폴더는 개발 검증용이며 앱 실행에 필요하지 않습니다.

## 알려진 제한 사항

- 데이터는 기록한 브라우저와 기기에 저장되며, 다른 기기나 브라우저와 동기화되지 않습니다.
- 브라우저 저장 공간이 제한될 수 있고 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. JSON 백업을 보관하세요.
- Google Fonts 연결은 선택 사항이며, 연결할 수 없어도 앱은 작동합니다.
- 오프라인 설치형 PWA 기능은 아직 포함하지 않았습니다.
