# Worklog

순수 HTML, CSS, JavaScript로 만든 한국어·영어 지원 업무일지입니다. 매일의 업무를 기록하고, 분류로 정리하고, 월별·날짜별·키워드별로 찾아볼 수 있습니다.

[Worklog 열기](https://thedevhublab.github.io/Worklog/)

[🇰🇷 한국어](README_KR.md) · [🇺🇸 English](README.md)

## 주요 기능

- **업무일지 작성** — 날짜, 제목, 상세 내용, 분류, 소요 시간을 입력해 기록을 추가하고 수정하거나 삭제할 수 있습니다. 제목은 필수이며 최대 80자, 상세 내용은 최대 3,000자입니다. 시간은 0~24시간 범위에서 30분 단위로 입력합니다.
- **월간 대시보드** — 이번 달 기록 수, 전체 기록 수, 기록을 남긴 날짜 수를 확인할 수 있습니다.
- **달력 및 월 선택** — 현지화된 월 선택 창으로 월별 기록을 살펴봅니다. 선택 언어에 맞춰 월 이름, 연도 표시, 날짜와 달력 컨트롤이 바뀝니다.
- **다양한 검색·정렬** — 월과 분류로 필터링하고, 제목·상세 내용·분류 이름을 검색할 수 있습니다. 최신순, 오래된순, 제목순(A–Z) 정렬을 지원합니다.
- **사용자 지정 분류** — 분류를 추가·이름 변경·삭제할 수 있습니다. 사용자 지정 분류는 한국어 이름과 영어 이름을 각각 입력해 언어를 바꿔도 알맞은 이름으로 표시됩니다. 기본 분류는 기획, 회의, 개발, 디자인, 운영, 기타입니다. 분류를 삭제해도 관련 업무일지는 보존되며, 가능한 경우 기타 분류로 이동합니다.
- **한국어·영어 인터페이스** — 화면에서 언어를 바꿀 수 있고 선택은 현재 브라우저에 저장됩니다. 기본 분류와 화면 문구는 언어에 맞게 표시되며, 사용자 지정 분류의 번역은 사용자가 직접 입력하고 관리합니다. 자동 번역 서비스는 사용하지 않습니다.
- **JSON 백업 및 복원** — 분류와 업무일지를 JSON 파일로 내보낼 수 있습니다. 백업 파일을 가져오면 현재 브라우저 데이터와 병합하며, ID가 같은 업무일지는 가져온 내용으로 교체됩니다.
- **반응형 화면** — 작은 화면에 맞춰 레이아웃이 조정되고, 입력 폼은 모바일에 알맞은 패널로 표시됩니다.

## 시작하기

최신 브라우저에서 `index.html` 파일을 열면 됩니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

1. 날짜와 제목을 입력하고 필요에 따라 상세 내용, 분류, 소요 시간을 추가합니다.
2. 월 선택, 분류 필터, 검색, 정렬 메뉴로 기록을 찾습니다.
3. 분류 관리에서 한국어와 영어 분류 이름을 설정합니다.
4. **JSON 내보내기**로 데이터를 백업하고, 가져오기로 백업 데이터를 복원하거나 병합합니다.

## 데이터 및 개인정보

Worklog에는 서버 데이터베이스나 계정 동기화 기능이 없습니다. 업무일지, 분류, 분류별 언어 이름, 언어 설정은 사용 중인 기기와 브라우저의 `localStorage`에 저장됩니다. 브라우저 사이트 데이터를 지우면 저장된 데이터가 사라질 수 있으므로 삭제 전에 백업 파일을 내보내세요. 다른 브라우저나 기기로 데이터가 자동 전송되지는 않습니다.

번역 API를 호출하지 않습니다. 글꼴은 가능할 때 Google Fonts에서 DM Sans와 Noto Sans KR을 불러오며, 연결할 수 없으면 기기의 기본 글꼴을 사용합니다.
